반영비율은 어떻게 계산하나요?

가중합 방식

각 평가 점수에 반영비율을 곱한 뒤 모두 더합니다. 예를 들어 중간 85점×30% + 기말 91점×40% + 수행평가 96점×30%라면 각각의 반영점수를 합산해 예상 최종점수를 구합니다.

예시 계산

85×0.30=25.5점, 91×0.40=36.4점, 96×0.30=28.8점이므로 합계는 90.7점입니다.

반영비율 합계는 100%

이 계산기는 세 평가 요소의 비율 합계가 정확히 100%일 때 계산합니다. 합계가 다르면 입력 오류를 안내합니다. 학교에서 다른 평가 구조를 사용한다면 실제 평가계획을 우선하세요.

FAQ — 목표점수를 역산하고 싶다면?
